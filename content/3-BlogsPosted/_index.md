### [Blog 3 - From Theory to Implementation: Data Engineering Challenges in a Real-World GenAI/RAG Project](3.3-Blog3/)
This blog focuses on applying Data Engineering principles to a real-world GenAI/RAG project on AWS, from building a Data Ingestion Pipeline and processing unstructured data to vector storage and retrieval, as well as query optimization through caching. In addition, the system uses a Batch Pipeline to evaluate model quality and CloudWatch for monitoring and alerting. Through this project, I identified three important principles: Decoupling, Asynchronous Serverless Processing, and Query Optimization. I also realized that Data Engineering plays an important role in building reliable Cloud infrastructure, automating data pipelines, and optimizing operating costs.
