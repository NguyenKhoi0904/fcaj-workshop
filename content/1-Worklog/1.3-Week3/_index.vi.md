### Kết quả đạt được tuần 3:

* Hiểu được Shared Responsibility Model và nắm được trách nhiệm của AWS cũng như khách hàng trong việc đảm bảo an toàn cho hệ thống trên nền tảng đám mây.
* Tìm hiểu và nắm được chức năng của các dịch vụ bảo mật và quản lý danh tính trên AWS, bao gồm:
  * AWS Identity and Access Management (IAM)
  * Amazon Cognito
  * AWS Organizations
  * AWS Identity Center (SSO)
  * AWS Key Management Service (KMS)
  * AWS Security Hub
* Thực hành triển khai và quản lý Amazon EC2 Linux Instance, bao gồm:
  * Tạo VPC và Security Group.
  * Khởi tạo và kết nối EC2 Linux Instance qua SSH.
  * Thay đổi EC2 Instance Type.
  * Tạo và quản lý EBS Snapshot.
  * Tạo Custom AMI.
  * Khởi tạo EC2 Instance từ Custom AMI.
* Có khả năng cài đặt môi trường và triển khai ứng dụng trên EC2 Linux Instance.
* Xây dựng RESTful API cho mô hình Machine Learning bằng FastAPI.
* Triển khai thành công ứng dụng FastAPI cùng mô hình Machine Learning lên Amazon EC2 Linux Instance.
* Bước đầu nắm được quy trình triển khai một ứng dụng Machine Learning lên nền tảng AWS, từ giai đoạn xây dựng mô hình, phát triển API, kiểm thử đến triển khai và vận hành trên môi trường đám mây.
