### Results Achieved in Week 3:
* Understand the Shared Responsibility Model and the respective responsibilities of AWS and customers in ensuring system security on the cloud platform.
* Learn and understand the functions of AWS security and identity management services, including:
  * AWS Identity and Access Management (IAM)
  * Amazon Cognito
  * AWS Organizations
  * AWS Identity Center (SSO)
  * AWS Key Management Service (KMS)
  * AWS Security Hub
* Gain hands-on experience deploying and managing Amazon EC2 Linux Instances, including:
  * Creating a VPC and Security Group.
  * Launching and connecting to an EC2 Linux Instance via SSH.
  * Changing the EC2 Instance Type.
  * Creating and managing EBS Snapshots.
  * Creating a Custom AMI.
  * Launching an EC2 Instance from a Custom AMI.
* Develop the ability to set up an environment and deploy applications on an EC2 Linux Instance.
* Build a RESTful API for a Machine Learning model using FastAPI.
* Successfully deploy the FastAPI application and Machine Learning model to an Amazon EC2 Linux Instance.
* Gain an initial understanding of the process of deploying a Machine Learning application on AWS, from model development, API development, and testing to deployment and operation in a cloud environment.
