### Results Achieved in Week 2:

* Gained an understanding of AWS network architecture and the roles of key components in Amazon VPC, including:
  * VPC
  * Public and Private Subnets
  * Internet Gateway
  * NAT Gateway
  * VPC Endpoint
  * Route Table
  * Security Group and Network ACL
* Understood the connectivity methods between on-premises infrastructure and AWS through:
  * VPN
  * AWS Direct Connect
* Understood the operating principles and use cases of:
  * Elastic Load Balancer (ELB)
  * Multi-VPC Architecture
  * VPC Security
  * Reachability Analyzer
* Learned the key concepts and components of Amazon EC2, including:
  * EC2 Instance Types
  * Amazon Machine Image (AMI)
  * Key Pair
  * Amazon Elastic Block Store (EBS)
  * Instance Store
  * EC2 Backup
* Learned about AWS services that support application deployment and scaling, including:
  * EC2 User Data
  * EC2 Metadata
  * Auto Scaling
  * Amazon Lightsail
  * Amazon EFS
  * Amazon FSx
  * AWS Application Migration Service (MGN)
* Gained an understanding of identity and access management on AWS through AWS Identity and Access Management (IAM).
* Gained hands-on experience managing access permissions with AWS IAM, including:
  * Creating and managing IAM Users, IAM Groups, and IAM Roles.
  * Switching between IAM Roles.
  * Creating an IAM User with the necessary permissions for lab exercises.
* Learned about AWS storage services and their key characteristics, including:
  * Amazon S3
  * Amazon S3 Glacier
  * AWS Snow Family
  * AWS Storage Gateway
  * AWS Backup
* Gained hands-on experience managing AWS account resources through:
  * Setting up and monitoring costs using AWS Budgets.
  * Creating support requests and learning about the AWS Support process.
* Gained hands-on experience deploying network infrastructure on AWS, including:
  * Creating and configuring an Amazon VPC.
  * Deploying an EC2 instance within a VPC.
  * Connecting to EC2 via SSH and configuring a NAT Gateway for a Private * Subnet.
  * Testing network connectivity using Reachability Analyzer.
  * Setting up monitoring and alerting with Amazon CloudWatch.
  * Creating and configuring a Site-to-Site VPN connection.
