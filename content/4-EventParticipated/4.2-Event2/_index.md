# Summary Report: “Agent Forge - Deepdive Day 1”

**Time:** 9:00 AM - 12:00 PM, Saturday, 01/08/2026  
**Location:** 26th Floor, Bitexco Financial Tower, 2 Hai Trieu Street, Saigon, Ho Chi Minh City 700000, Vietnam.  
**Role:** Attendee  
**Speakers:** <br>
- Nghia Tran - Agentic SA
- Anh Pham - Cloud Consultant, G-AsiaPacific Vietnam

##### Main Content:
This was an L300 deep-dive workshop on Amazon Bedrock Agent Core, designed for enterprises that want to build production-ready Agentic AI systems.

The theoretical session covered the following main topics:
 - **Introduction to Agentic AI:** Explained the concept of autonomous AI, its ability to plan and execute tasks step by step, and levels of autonomy ranging from deterministic workflows to fully autonomous systems.
 - **Amazon Bedrock Agent Core:** A service that helps manage, deploy, and operate AI agents. The system follows industry standards for performance, scalability, and security.
 - **Core Components of Agent Core:**
    - **Runtime Environment:** A serverless environment for running agents, using *Firecracker MicroVM* technology to isolate resources.
    - **Identity:** An authentication and authorization layer using *JSON Web Tokens (JWT)* and *Workload Access Token*.
    - **Gateway:** A middleware layer that connects agents with different tools through the *MCP (Model Context Protocol)*, supporting centralized control and *human-in-the-loop* capabilities.
 - **Security and Connectivity:** Discussed connecting agents to a VPC network and using *AWS PrivateLink* to ensure that internal data is not exposed to the public network.

The hands-on session focused on guiding participants through the Runtime, Gateway, and Identity services introduced in the theoretical session, as well as showing participants how to set up the necessary environments for the practical exercises.

#### Key Takeaways
Through the Agent Forge - Deepdive Day 1 event, I gained a clearer understanding of Agentic AI and how to build AI Agents that can independently plan, execute tasks, and interact with external services. I also learned about the architecture of Amazon Bedrock Agent Core, including the Runtime, Identity, and Gateway components, as well as the role of each component in deploying and operating AI Agents. In addition, I recognized the importance of security when deploying AI systems through the combination of Amazon VPC and AWS PrivateLink. The hands-on session helped me become familiar with the process of configuring the environment and deploying Bedrock Agent Core services, allowing me to better understand the connection between theory and practical applications.
